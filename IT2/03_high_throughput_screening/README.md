# Step 03: High-Throughput Screening

This step runs the high-throughput screening workflow for the selected `IT2` candidates.

## Store Here

- `inputs/`: selected candidates from Step 02.
- `scripts/`: STOIC and CALPHAD run scripts.
- `stoic_results/`: STOIC outputs.
- `calphad_results/`: CALPHAD outputs.
- `outputs/`: merged or reduced tables used for final filtering.

## Expected Output

A combined property table for `04_final_filtering/`.
