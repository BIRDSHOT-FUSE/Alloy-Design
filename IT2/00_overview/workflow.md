# Workflow

This file records the ordered `IT2` workflow.

## Ordered Steps

1. Build the candidate composition space with Nimplex.
2. Evaluate the generated compositions with the FLARE workflow, including calculations, filtering, survivor sets, and plots.
3. Run high-throughput screening on the selected survivor set.
4. Apply final filtering to the property results.
5. Report the final candidate list.

## Handoff Rule

Each step should produce a clear output file or directory that becomes the input to the next numbered step.
